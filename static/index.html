      초안
      
        
      AI가 작가 지침대로 쓴 네이버 블로그 초안이 모두 여기에 보관됩니다. 고쳐서 저장하고, 본문만 복사해 스마트에디터에 붙여 넣거나 docx로 내려받으세요.

      설정

      AI 글쓰기 초안 작성
      
        
      
      
      
      기획안에서 AI 초안 쓰기를 누르면 아래 작가 지침과 블로그 기억을 바탕으로 네이버 블로그 초안을 씁니다. 기본은 Gemini이고, 모델은 항상 그때 쓸 수 있는 최고 버전을 자동으로 고릅니다(Flash·Lite 안 씀).
      
      
      
        
        
        
      
      
      
      
        
      Gemini로 자동 작성 (Antigravity CLI)
      
        
      
          
          
          
        
      
        
      PC마다 한 번씩 필요해요 (집·회사 따로). ②에서 열린 검은 창에서 구글 로그인을 마치면 창을 닫아도 돼요. 버튼이 안 되면 아래 방법으로 직접 설치하세요.
      
        
        
          
      1. 시작 메뉴에서 PowerShell을 열고 irm https://antigravity.google/cli/install.ps1 | iex 를 실행하세요.
        2. 
          
      2. 새 명령 창(cmd)에서 agy 를 한 번 실행해 Gemini 구독 계정으로 로그인하세요. 로그인 후 Ctrl+C로 나와도 돼요.
        3. 
          
      3. AI 연결 확인을 눌러 Antigravity CLI를 찾았는지 확인하세요.
        4. 
        
      
        
      Google이 개인 계정(Google AI Pro·Ultra)의 Gemini CLI 사용을 끝내고 Antigravity CLI로 옮겼습니다. 구독 한도로 쓰고 따로 돈이 나가지 않아요. PC에 GEMINI_API_KEY가 있어도 그 키를 빼고 실행하고, 실패해도 유료 API로 넘어가지 않고 멈춰서 이유를 보여 줍니다. 모델은 Antigravity 기본 모델을 쓰고, 특정 모델로 고정하려면 아래에 이름을 적으세요.
      
        
        
      
      
      
      
        
      Claude로 자동 작성 (Claude Code · Max 구독 필요)
      
        
        
          
      1. 이 PC에 Claude Code가 설치되어 있고 Max 계정으로 로그인되어 있으면 끝이에요. (명령 창에서 claude를 한 번 실행해 로그인)
        2. 
          
      2. AI 연결 확인을 눌러 Claude Code를 찾았는지 확인하세요.
        3. 
        
      
        
      사용량은 Max 구독 한도에서 차감되고 따로 돈이 나가지 않아요. PC에 Claude API 키(ANTHROPIC_API_KEY)가 설정돼 있어도 이 프로그램은 그 키를 빼고 실행해서 구독으로만 씁니다. 초안 1편에 2~5분 걸릴 수 있어요.
      
        
      
      
      
      
        
      붙여넣기 방식
      
        
        
          
      1. AI 초안 쓰기를 누르면 작가 지침과 글감 데이터가 담긴 요청문이 만들어져요. 복사해서 claude.ai나 Gemini에 붙여 넣으세요.
        2. 
          
      2. Claude 프로젝트(또는 Gemini Gems)에 작가 지침을 미리 넣어 두면 짧은 요청문만 붙여 넣으면 돼요.
        3. 
          
      3. AI가 쓴 초안을 복사해 프로그램에 붙여 넣으면 초안 탭에 보관되고, 이미지 프롬프트 카드·docx 저장이 그대로 돼요.
        4. 
        
      
        
      
      
      
      
      
        최신 모델 확인용 Gemini 키 (선택 · 무료 · 글쓰기에는 쓰지 않음)
        
        
        
      이 프로그램은 유료 API로 글을 쓰지 않습니다. 이 키는 '지금 나온 최고 버전 모델 이름'을 확인하는 데만 쓰고(모델 목록 조회는 무료), 글은 항상 구독(Antigravity·붙여넣기·Claude Max)으로만 씁니다. 키가 없어도 됩니다.
      
      
      
      
      
        
        
      
      
      
      
        작가 지침 (md) · 초안을 쓸 때 AI가 따르는 규칙
        
      
          
          
          
        
      
        
      글감에 맞춰 셋 중 하나가 자동으로 쓰여요. 고치면 다음 초안부터 반영돼요. 저장 위치: …
      
        
        
      
      
      
      
      
        블로그 기억 (md) · 자동으로 쌓이는 기록
        
      최근 초안·발행한 글·마무리 문장·저장한 글감을 프로그램이 자동으로 정리합니다. AI가 같은 주제와 같은 마무리를 반복하지 않게 해 줍니다. 저장 위치: …
      
        
      
      
      
    
      

    
      
      
      내 문체 학습 초안이 내가 쓴 것처럼
      
      
      블로그 ID를 넣고 반응이 좋았던 글을 골라 학습시키면, 문장 길이·어미·도입과 마무리·소제목 짓는 법·자주 쓰는 표현을 프로필로 만들어 모든 초안에 적용합니다. 구성은 작가 지침, 문장은 내 문체로 씁니다.
      
      
      
        
      
          
          
      
          
      불러온 글은 문체 학습에 쓰고, 이미 쓴 주제는 추천 순위를 낮추고 초안이 같은 주제를 반복하지 않게 합니다.
      
          
          
      위에 블로그 ID를 넣고 "내 글 불러오기"를 누르면 최근 글이 여기 나와요. 학습할 글에 체크하세요.
      
          
        
      
        
      
          학습된 프로필 직접 고쳐도 돼요
          
          
      
        
      
      
      
    
      

    
      
      
      스스로 일하기 · 공부하기
      
      
      
        
      
          
      매일 아침 글 2편
      
          
          
      
          
      상시 주제는 상시 키워드 검증에서 '1년 내내 찾음'·검색량 큰 순, 오늘 최적 주제는 오늘의 글 계획(요일 코너·최근 7일 이슈)으로 골라요. 그 시각에 PC가 꺼져 있으면 켜진 뒤 그날 한 번 실행해요.
      
          
      자동 실행
      
          
          
          
      오전 7시~밤 11시 사이에만 자동으로 분석해요. 결과는 열 때마다 최신으로 보여요.
      
          
          
      오늘의 추천 상위 글감 중 아직 안 쓴 것으로, 작가 지침(Gems)대로 써서 초안 탭에 넣어 둬요. 관심 없음·내 블로그에 이미 있는 주제는 건너뜀.
      
        
      

        
      
          
      내 선택 반영
      
          
      저장·발행한 분야는 올리고, 기획안에서 관심 없음을 누른 글감은 다음부터 내립니다.
      
          
      
        
      
      
      
    
      

    
      
      
      
        
      분석 속도
      느릴수록 후보를 더 많이 모아 정확해집니다. 평소엔 ‘빠름’이면 충분해요.
      
        
      
      
      
      
      
        
      내 블로그 유입 검색어 선택
      어제 내 블로그로 사람을 데려온 검색어를 넣으면 그 주제를 넓혀서 1순위로 추천합니다.
      
        
      
      
      
      
        
      추천에 포함할 것
      
        
      
      
    
      



    
      
      
      검색 데이터 연결 선택
      키를 넣으면 실제 검색수·블로그 발행량으로 분석 단계가 올라가요. 이미 저장된 칸은 비워 두면 그대로 유지돼요.
      
      
      
        
        
      
      
    
      
    
      
    
      

    
      
      
      
        
      
          
      네이버 검색광고 추천
      
          
        
      
        
      실제 월간 검색수(PC·모바일)와 경쟁 정도를 가져옵니다. 광고비를 쓰지 않아도 무료로 발급됩니다.
      
        
        
          
      1. manage.searchad.naver.com에 네이버 아이디로 로그인 (새 ‘네이버 광고’ 화면에서는 이 메뉴가 안 보일 수 있어요)
        2. 
          
      2. 위쪽 메뉴 도구 → API 사용 관리 → 네이버 검색광고 API 서비스 신청
        3. 
          
      3. 나오는 액세스라이선스 · 비밀키 · CUSTOMER_ID 3개를 아래에 붙여넣기
        4. 
        
      
        
      Customer ID는 숫자로 된 광고 계정 번호예요. 로그인 후 주소창의 customers/숫자 부분에서도 확인할 수 있어요. 붙여넣을 때 앞뒤 공백이 섞이지 않게 해 주세요.
      
        
        
        
      
      

      
      
        
      
          
      NAVER API HUB 추천
      
          
        
      
        
      블로그 발행량, 최근 7일 새 글, 지식iN 질문 수, 검색어 트렌드를 가져옵니다. 2026년 7월 31일부터 네이버 검색 API는 이곳에서만 신청할 수 있습니다.
      
        
        
          
      1. 네이버 클라우드 콘솔에 로그인
        2. 
          
      2. NAVER API HUB에서 앱(애플리케이션) 만들기
        3. 
          
      3. 사용할 API에 검색(블로그·지식iN)과 검색어 트렌드 추가
        4. 
          
      4. 앱의 인증 정보에 있는 Client ID와 Client Secret을 붙여넣기
        5. 
        
      
        
      예전에 developers.naver.com에서 받은 키도 그대로 넣으면 자동으로 인식합니다(2027년 6월까지 사용 가능).
      
        
        
      
      

      
      
        
      
          
      카카오 선택
      
          
        
      
        
      다음 블로그 발행량을 참고용으로 함께 보여줍니다.
      
        
        
          
      1. developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가
        2. 
          
      2. 앱 키의 REST API 키를 붙여넣기
        3. 
        
      
        
      
      

      
      
        
      
          
      내 홈페이지 연계 선택
      
          
        
      
        
      블로그 글에서 연결할 내 사이트를 등록하세요. 사이트 서비스와 맞는 키워드에는 내 사이트 연계 표시가 붙고, 기획안에 링크 넣을 위치와 연결 문구가 추가됩니다.
      
        
        
        
      사이트에서 할 수 있는 것
      
        
      
        
      내 사이트 도구 목록 
      
        
      한 줄에 도구 하나: 이름 | 주소 | 연결할 검색어(쉼표로) | 한 줄 설명. 검색어가 들어간 글감에는 이 도구가 자동으로 붙고, 초안에 '이용 방법' 섹션과 정확한 링크가 들어가요.
      
        
        
        
      
      
      

    
      
    
      
      
      프로그램
      
      
      
          집·회사 PC 같이 쓰기 
          
      초안·지침·블로그 기억·설정·키를 OneDrive 같은 동기화 폴더에 두면, 다른 PC에서도 같은 폴더를 고르는 것만으로 똑같이 이어서 씁니다. 두 PC를 동시에 켜 두면 자동 분석·자동 초안은 먼저 켠 PC에서만 돌아요.
      
          
      
            
            
            
            
          
      
        
      
      
      
        
      저장 위치
      … · 키와 기록은 이 폴더에만 저장되고 다른 곳으로 보내지 않습니다.
      
      
      
    
      
  
      

      



      

      
  
  
      

      




  
      
    
      
      
      
        
      내 블로그 유입 검색어
      
        
      어제 내 블로그로 사람을 데려온 검색어를 넣으면, 오늘 분석의 1순위 씨앗으로 넓혀서 씁니다. 선택 사항이에요.
      
      
      
      
    
      
    
      
      
        
        
      1. 네이버 블로그 → 내 블로그 통계(크리에이터 어드바이저)
        2. 
        
      2. 유입 분석 → 검색 유입에서 어제 날짜를 고르고 검색어 목록을 복사
        3. 
        
      3. 아래 칸에 붙여넣기 (줄바꿈이나 쉼표로 구분, 최대 30개)
        4.
