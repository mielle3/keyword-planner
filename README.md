# 키워드 플래너 (네이버 블로그용)

내 블로그 주제 안에서 **오늘 쓰면 좋은 키워드**를 데이터로 찾아 순위를 매기고, 키워드마다 **바로 쓸 수 있는 글 기획안**을 만들어 주는 프로그램입니다.

## 실행

1. 압축을 원하는 폴더에 풉니다.
2. 실행 파일을 더블클릭합니다.
   - Windows: **`실행_윈도우.bat`**
     - Python이 없으면 자동으로 설치합니다. 설치가 끝나면 창을 닫고 한 번 더 실행하세요.
     - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
   - Mac: **`실행_맥.command`**
     - 처음 한 번은 우클릭 → 열기를 선택하세요.
3. 브라우저가 열립니다(`http://127.0.0.1:8765`). 검은 창은 프로그램 본체라 쓰는 동안 닫지 마세요.

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| **오늘의 추천** | 처음 한 번 내 블로그 주제(네이버 공식 32개 중)를 고르고, 매일 **오늘 추천 받기**를 누릅니다. 결과는 **오늘 쓸 글 TOP 10**, **오늘의 이슈**, **주제별 순위표**(사회 뉴스·문화 뉴스·경제 뉴스 등 분야별 탭 포함) 순으로 나옵니다 |
| **선제 글감** | 콘서트 티켓팅, 내한·팬미팅, 개봉·출시, 내년 달라지는 제도처럼 **곧 검색이 몰릴 주제**를 먼저 찾습니다. 관심 키워드(아티스트·행사·브랜드)를 등록해 두면 "악동뮤지션 콘서트 예매" 같은 예고 신호를 따로 감시합니다. **선점 지수**와 **발행 권장 시점**, 다가오는 날짜(D-day)를 함께 보여 줍니다 |
| **상시 키워드** | 유행과 상관없이 1년 내내 찾는 키워드 사전(33개 분야 약 650개, `evergreen.json`). **상시성 검증하기**를 누르면 네이버 데이터랩 24개월 월별 추이 · 검색광고 월간 검색수 · 블로그 글 수로 상시 / 대체로 상시 / 계절형(피크 달) / 하락 / 검색 적음을 판정합니다. 검증된 상시 키워드는 오늘의 추천에 분야별로 매일 돌아가며 들어갑니다. 위쪽 칸에서는 키워드를 직접 넣어 연관 키워드까지 분석할 수 있습니다 |

**생활 제도 일정 (매년 같은 시기의 신청·납부·마감)**
- 트렌드·뉴스는 검색이 오른 뒤에야 잡히므로, 해마다 정해진 일정은 달력으로 미리 넣습니다: 지역가입자 건보료 조정(11월), 종부세 고지·납부(11/20~12/15), 수능 이후 입시 일정, 연말정산 미리보기·간소화, 고향사랑기부제 연말 마감, 에너지바우처, 국가장학금 1차, 국가건강검진 연말 마감, 자동차세(12월·1월 연납), 새해 달라지는 제도, 소상공인 정책자금 공고, 부가세·종소세·근로장려금·재산세·주민세 등.
- 시작 2주 전부터 '생활 제도 일정' 탭에 나오고, 3주 안에 마감되는 일정은 1면 TOP 10에 2자리까지 먼저 올라갑니다. 날짜는 통상 시기이므로 글에는 그해 공고 날짜를 확인해 적습니다.
- 상시 키워드 중 '계절형'으로 판정된 것은 피크 달(이번 달·다음 달)에 추천에 들어갑니다.

**상시성 판정 기준 (최근 12개월 월별 검색 추이 기준)**
- 상시: 변동계수 0.25 미만, 가장 많은 달이 평균의 1.5배 미만
- 계절형: 변동계수 0.45 이상 또는 가장 많은 달이 평균의 1.9배 이상 (평균의 1.4배를 넘는 달을 피크 달로 표시)
- 하락: 직전 12개월보다 35% 이상 감소 · 검색 적음: 월 검색 100회 미만
- 점수(추정): 검색수 40% + 꾸준함 35% + 경쟁 적음(검색 1회당 블로그 글 수) 25%
- 사전에 넣지 않은 것: 대출·보험 견적·금리처럼 저품질 위험이 큰 키워드, 특정 연도·행사 키워드
| **저장함** | ★로 담은 키워드를 쓸 예정 / 작성 중 / 발행 완료로 관리합니다 |
| **설정** | API 키 입력, 연결 확인, 오늘 API 사용량 |

카드나 표의 행을 누르면 오른쪽에 **기획안**이 열립니다. 들어 있는 항목은 다음과 같습니다.
- 글 기획: 왜 지금 써야 하는지, 누가 읽는지, 무엇을 담을지, 어떻게 차별화할지
- 추천 제목 2개
- 소제목 구성
- 도입부 예시
- 태그 10개
- 제목 검사기
- 수치와 점수 계산 근거
- 지금 상위에 있는 블로그 글

**기획안 전체 복사** 버튼으로 한 번에 복사할 수 있습니다.

## 내 홈페이지 연계 (예: 떠나셈)

**설정 → 내 홈페이지 연계**에 세 가지를 등록합니다.
- 사이트 이름과 주소
- 사이트에서 할 수 있는 것: 공연·티켓 예매, 여행·투어, 숙소·호텔, 맛집·예약, 쇼핑·상품, 교육·클래스 중에서 고릅니다.

등록하면 이렇게 바뀝니다.
- 서비스와 맞는 키워드에 **"떠나셈 연계"** 표시가 붙습니다. 원하면 순위에서도 우대합니다(+6점, 끌 수 있음).
- 기획안에 **링크 넣을 위치**, 바로 쓸 수 있는 **연결 문구 3개**, **"떠나셈에서 예매하는 방법"** 소제목이 추가됩니다.
- 링크는 1~2개만 넣고 링크 앞뒤로 직접 정리한 정보를 충분히 쓰세요. 정보 없이 외부 링크만 많은 글은 네이버 검색에서 품질이 낮게 평가될 수 있습니다(일반적으로 알려진 경향).

**선점 지수(0~100)** 계산 방법:
- 기본 비율: 상승세 40% + (100 − 포화도) 35% + 수요 25%
- 포화도는 검색수에 비해 블로그 글이 얼마나 많은지를 뜻합니다.
- 블로그 글 수 데이터가 없으면 상승세 60% + 수요 40%로 계산합니다.
- 이 가중치도 임의로 정한 값이며, 등급은 68점 이상이면 "지금 선점", 55점 이상이면 "준비해 두기"입니다.

## 분석 단계

| 단계 | 필요한 것 | 순위 근거 |
|---|---|---|
| 1단계 기본 | 없음 | 네이버 자동완성(실제 검색 문구), 구글 트렌드, 시즌 캘린더로 **추정** |
| 2단계 검색량 | + 네이버 검색광고 키 (무료) | **실제 월간 검색수**(PC·모바일)와 경쟁 정도 |
| 3단계 정밀 | + NAVER API HUB 키 (무료) | **블로그 발행량, 최근 7일 새 글, 검색어 트렌드, 지식iN 질문 수** |

**기회 점수(0~100)** 계산 방법:
- 기본 비율: 수요 35% + 상승세 25% + (100 − 경쟁) 25% + 글감 적합도 15%
- 데이터가 없는 항목은 빼고 나머지 비율을 다시 맞춥니다.
- 이 가중치는 임의로 정한 값입니다. 각 키워드의 기획안 창에 항목별 점수와 근거가 표시됩니다.
- 등급: 70점 이상 높음, 55점 이상 보통, 그 밖은 낮음

## API 키 발급 (모두 무료)

### ① 네이버 검색광고 → 실제 월간 검색수
1. [searchad.naver.com](https://searchad.naver.com)에 네이버 아이디로 로그인합니다. 광고주 가입 화면이 나오면 가입합니다. 광고비를 쓰지 않아도 됩니다.
2. 오른쪽 위 **도구 → API 사용 관리**로 들어갑니다.
3. **네이버 검색광고 API 서비스 신청**을 누릅니다.
4. 화면에 나온 **액세스 라이선스(API Key)**, **비밀키(Secret Key)**, **CUSTOMER_ID** 3개를 프로그램 **설정 → 네이버 검색광고**에 붙여넣습니다.

### ② NAVER API HUB → 블로그 발행량·검색어 트렌드·지식iN
네이버 검색 API는 **2026년 7월 31일부터 네이버 클라우드의 NAVER API HUB에서만 새로 신청**할 수 있습니다.
1. [네이버 클라우드 콘솔](https://console.ncloud.com)에 네이버 아이디로 로그인합니다.
2. 처음이면 회원 정보와 결제 수단 등록을 요구할 수 있습니다. 무료 사용량 안에서는 요금이 나가지 않는 것으로 안내되어 있지만, 정확한 무료 범위는 콘솔의 요금 안내에서 확인해 주세요.
3. 서비스 목록에서 **NAVER API HUB**를 찾아 들어갑니다.
4. **애플리케이션(앱) 등록**을 누르고 사용할 API로 **검색(블로그, 지식iN)**과 **검색어 트렌드**를 고릅니다.
5. 등록한 앱의 **인증 정보**에서 **Client ID**와 **Client Secret**을 복사해 프로그램 **설정 → NAVER API HUB**에 붙여넣습니다.

※ 계정 전체용 키(IAM 액세스 키)가 아니라 **API HUB 앱의 Client ID/Secret**이어야 합니다.
※ 예전에 developers.naver.com에서 받은 키가 있다면 그대로 넣어도 자동으로 인식합니다(2027년 6월 30일까지 사용 가능하다고 알려져 있음).

### ③ 카카오 (선택) → 다음 블로그 글 수
1. [developers.kakao.com](https://developers.kakao.com) → 내 애플리케이션 → 애플리케이션 추가를 누릅니다.
2. **앱 키 → REST API 키**를 프로그램 **설정 → 카카오**에 붙여넣습니다.

키를 넣은 뒤 **저장 → 연결 확인**을 누르면 각 키가 제대로 연결됐는지 바로 표시됩니다.

## 내 블로그 유입 검색어 (선택)

크리에이터 어드바이저의 **유입 분석 → 검색 유입**에서 어제 검색어를 복사해 **오늘의 추천 → 내 블로그 유입 검색어**에 붙여넣으세요. 이미 내 블로그로 사람을 데려온 검색어를 넓혀서 오늘 분석의 1순위 씨앗으로 씁니다.

## 저장 위치와 공유

- 키, 기록, 저장함은 모두 **`data` 폴더**에 저장됩니다. 폴더째 옮기면 그대로 이어서 쓸 수 있습니다.
- 다른 사람에게 줄 때는 **`data` 폴더를 빼고** 주세요. 내 API 키가 들어 있습니다.

## 알아둘 점

- 네이버 자동완성과 시그널 실시간 검색어는 공식 API가 아닙니다. 해당 사이트 사정에 따라 막힐 수 있고, 막혀도 나머지 데이터로 분석은 계속됩니다.
- 네이버 API 한도는 하루 기준으로 검색 25,000회, 검색어 트렌드 1,000회입니다. 설정 화면에서 오늘 사용량을 볼 수 있습니다.
- 제목·기획안 문장은 AI가 아니라 검색 의도별 틀로 만든 초안입니다. 내 경험과 사진을 더해 완성하세요.

## AI 초안 (v11.21-32~)

- **AI 초안 쓰기**: 기획안 아래 버튼을 누르면 AI(기본 Gemini)가 **작가 지침**대로 네이버 블로그 초안을 씁니다(1~3분). 쓰는 동안 웹 검색으로 공식 자료를 확인하도록 켤 수 있습니다.
- **초안 탭**: 쓴 초안이 모두 보관됩니다. 미리보기/편집, 상태(초안·수정 중·발행 완료), 본문 복사(스마트에디터 붙여넣기용), 전체 복사, docx 저장, 다시 쓰기, 삭제.
- **작가 지침(md)**: Gems 지침을 정리한 `writer_guide.md`가 처음에 `memory/작가_지침.md`로 복사됩니다. 설정 → AI 글쓰기에서 고칠 수 있습니다.
- **블로그 기억(md)**: 최근 초안·발행한 글·마무리 문장·저장한 글감을 `memory/블로그_기억.md`에 자동으로 정리해, 같은 주제·같은 마무리를 반복하지 않게 합니다.
- **초안을 쓰는 방법 (설정 → AI 글쓰기)**
  - **프로그램이 직접 완성**: 글감에서 *AI 초안 쓰기*를 누르면 뒤에서 작가 지침(Gems)대로 쓰고 → 출력 양식 17개 항목(확인 일자·핵심만 먼저 보기 ✔·목차·질문형 소제목 5~6개·섹션별 핵심 한 줄 박스·표 3개 이상·이미지 위치 6곳·한눈에 요약·자주 묻는 질문·분량 3,000자·본문 URL 없음·면책 문구·참고 자료·카드뉴스 프롬프트 6개·태그 10~15개·태그 맨 끝)을 프로그램이 검사하고 → 빠진 곳이 있으면 한 번 더 고쳐 쓰게 한 뒤 초안 탭에 보관합니다. 오른쪽 아래에 진행 상황이 보이고, 다른 화면을 봐도 계속 씁니다. 진행 칸의 **취소**로 언제든 멈출 수 있습니다.
  - **미리 써 두기**: 자동 분석이 끝날 때마다 오늘의 추천 상위 글감 중 아직 안 쓴 것으로 하루 2편(설정에서 0~5편)까지 초안을 미리 써 둡니다.
  - **Gemini 구독 (기본)**: PC에 설치한 Antigravity CLI(`agy`, 구글 계정 로그인)가 씁니다. Google이 2026년 개인 계정(Google AI Pro·Ultra)의 Gemini CLI 사용을 끝내고 Antigravity CLI로 옮겼습니다. 설치: PowerShell에서 `irm https://antigravity.google/cli/install.ps1 | iex` → 새 명령 창에서 `agy` 를 한 번 실행해 로그인. 구독 한도에서 쓰고 추가 비용이 없습니다. PC에 `GEMINI_API_KEY`가 있어도 그 키를 빼고 실행합니다.
  - **모델**: Antigravity 기본 모델을 씁니다. 설정의 모델 칸에 이름을 적으면 그 모델로 고정됩니다.
  - **붙여넣기**: 작가 지침이 담긴 요청문을 복사해 Gemini(Gems)나 claude.ai(프로젝트)에 붙여 넣고, 결과를 다시 붙여 넣습니다. 설치 없이 무료.
